# Source Priority

Use this priority order when selecting visuals and screenshots.

## P0: Primary factual sources

Use as factual anchors.

- Official company blogs and announcements
- Product documentation
- Release notes / changelogs
- Pricing pages
- Model cards and system cards
- Research papers and arXiv pages
- GitHub releases, README, official repos
- Official benchmark or leaderboard pages

## P1: Named primary people

Use as strong context or intent signals, but still separate opinion from fact.

- Founder posts
- Researcher posts
- Core developer posts
- Official employee explanations
- Conference slides or demos from original presenters

## P2: Developer/community evidence

Use for friction, adoption, and real-world problems.

- GitHub issues and PR discussions
- Hacker News threads
- Reddit technical discussions
- Stack Overflow / forum posts when relevant
- Product Hunt comments

## P3: Reputable media

Use as secondary confirmation or timeline context.

- The Verge
- TechCrunch
- MIT Technology Review
- Wired
- Ars Technica
- Financial Times / Bloomberg / Reuters when available

## P4: Ordinary social posts

Use only for sentiment, anecdotes, or article texture.

- X/Twitter user posts
- Personal blog reactions
- Threads, Mastodon, Bluesky, etc.

Never use P4 as the sole basis for factual claims.
