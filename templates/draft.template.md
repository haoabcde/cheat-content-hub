## 写作自检

- [ ] 结构：开头有明确 hook，段落推进不绕路
- [ ] 证据：关键判断有事实、案例或数据支撑
- [ ] 参考：如有对标文章，已先做 layout-audit.md，且只借鉴不照搬
- [ ] 封面：横版封面有冲突/场景/数字，不是 UI 卡片
- [ ] 配图：图片数量匹配正文长度，裁切清楚，重点信息手机可读
- [ ] 图注：每条图注都是给读者看的解释，不是素材备注
- [ ] HTML：有首屏、分节、引用/分割线、图片节奏，不是普通段落流
- [ ] 表达：语言自然，少套话，读者能一路读下去
- [ ] 传播：读完后有转发、收藏或评论的理由
- [ ] 复制：copy 版 HTML 已把本地图片转成 data URI
