# Migration: v1.4 → v1.5

## WHAT

将 `.cheat-state.json` 从 flat 结构升级为 multi-format 结构：
- 新增 `default_format` 字段（顶层）
- 新增 `formats` 对象，包含 `video`、`article`、`xhs` 三个子对象
- 将顶层的 `rubric_version`、`calibration_samples`、`pending_retros`、`shoots`、`consecutive_directional_errors`、时间戳等字段迁移到 `formats.video` 下
- 新增 `formats.article` 和 `formats.xhs`（使用默认值）

## WHY

cheat-on-content 从视频专用扩展为支持公众号和小红书的多格式内容创作工具。每种格式需要独立追踪校准进度、待复盘队列和 rubric 版本。

## HOW

运行 `/cheat-migrate`，或手动执行以下步骤：

### 自动迁移

`/cheat-migrate` 会：
1. 读取当前 `.cheat-state.json`
2. 创建 `formats` 对象
3. 将以下字段从顶层迁移到 `formats.video`：
   - `rubric_version`
   - `content_form`
   - `calibration_samples`
   - `calibration_samples_at_last_bump`
   - `consecutive_directional_errors`
   - `pending_retros`
   - `shoots`
   - `baseline_plays`
   - `last_bump_at`
   - `last_bump_self_audited`
   - `last_published_at`
   - `last_published_file`
   - `last_retro_at`
   - `last_prediction_self_scored`
   - `last_self_scored_at`
4. 创建 `formats.article` 和 `formats.xhs`，使用默认值：
   ```json
   {
     "rubric_version": "v0",
     "content_form": "wechat-article",  // 或 "xhs-post"
     "calibration_samples": 0,
     "calibration_samples_at_last_bump": 0,
     "consecutive_directional_errors": [],
     "pending_retros": [],
     "baseline_plays": null,
     "last_bump_at": null,
     "last_bump_self_audited": false,
     "last_published_at": null,
     "last_published_file": null,
     "last_retro_at": null,
     "last_prediction_self_scored": false,
     "last_self_scored_at": null
   }
   ```
5. 添加顶层 `default_format` 字段：
   - 如果旧 `content_form` 是 "opinion-video" → `default_format = "video"`
   - 否则 → 询问用户
6. 删除顶层已迁移的字段
7. 更新 `schema_version` 为 "1.5"

### 手动迁移

如果自动迁移失败，手动编辑 `.cheat-state.json`：

1. 在顶层添加 `"default_format": "video"`
2. 添加 `formats` 对象：
   ```json
   "formats": {
     "video": {
       // 将顶层的 rubric_version, calibration_samples, pending_retros,
       // shoots, consecutive_directional_errors, 时间戳等字段复制到这里
     },
     "article": {
       "rubric_version": "v0",
       "content_form": "wechat-article",
       "calibration_samples": 0,
       "calibration_samples_at_last_bump": 0,
       "consecutive_directional_errors": [],
       "pending_retros": [],
       "baseline_plays": null,
       "last_bump_at": null,
       "last_bump_self_audited": false,
       "last_published_at": null,
       "last_published_file": null,
       "last_retro_at": null,
       "last_prediction_self_scored": false,
       "last_self_scored_at": null
     },
     "xhs": {
       "rubric_version": "v0",
       "content_form": "xhs-post",
       "calibration_samples": 0,
       "calibration_samples_at_last_bump": 0,
       "consecutive_directional_errors": [],
       "pending_retros": [],
       "baseline_plays": null,
       "last_bump_at": null,
       "last_bump_self_audited": false,
       "last_published_at": null,
       "last_published_file": null,
       "last_retro_at": null,
       "last_prediction_self_scored": false,
       "last_self_scored_at": null
     }
   }
   ```
3. 删除顶层已迁移到 `formats.video` 的字段
4. 更新 `"schema_version": "1.5"`

## Manual fallback

如果手动迁移也不行，最安全的方式：
1. 备份当前 `.cheat-state.json`
2. 删除它
3. 重新运行 `/cheat-init`，选择你的默认格式
4. 手动将旧的 `calibration_samples` 等数值填回对应格式

## 兼容性

- 新版 skill 使用 `state.get(field, default)` 读取，旧 schema 缺少 `formats` 字段时会自动降级
- `hooks/session-start.sh` 有向后兼容逻辑，检测到无 `formats` 对象时回退到读顶层字段
- 不跑 migrate 也能用，但所有格式的校准进度会从 0 开始
