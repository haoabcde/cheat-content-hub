# 自建配图与排版 skill 指南

多格式工作流里有两个环节**高度个人化**，cheat-on-content 不提供现成实现：

- **配图**（封面风格、插图风格、图注语气）——你的视觉风格就是你的品牌，别人的拿来用就是盗版气质
- **排版**（字号、行高、分节样式、强调色）——平台版式偏好因人而异，且各平台编辑器约束不同

本文档讲怎么给自己建这两个 skill。建好后，cheat-init 的 Phase 5 清单和主路由会自然识别它们。

## 配图 skill（建议命名 cheat-visual 或 <你的名>-visual）

它该拥有的内容：

1. **封面规格**：平台尺寸（公众号 2.35:1 横版、小红书 3:4 竖版）、标题字数上限、你的固定视觉元素（栏目标签 / 色系 / 字体）
2. **插图角色体系**：照 [wechat-editorial-workflow.md](wechat-editorial-workflow.md) 第 3 节的六类图角色（锚点 / 冲突 / 数据 / 机制 / 人物场景 / 收束），为每一类写清楚你这的产出形式——真截图、重绘简化图、还是生成图
3. **生成图提示词模板**：如果走 AI 生图，把风格约束写死（色调、构图、禁忌元素），别让每次生图都重新掷骰子
4. **contact-sheet 产物约定**：一次出完所有图的缩略拼版，方便人眼过一遍质量

SKILL.md frontmatter 的 description 里写清触发词（"配图"、"封面"、"插图"），主路由就能在用户说这些词时找到它。

## 排版 skill（建议命名 neat-freak 或 <你的名>-layout）

它该拥有的内容：

1. **主题文件**：正文两侧边距、段落行高（公众号建议接近 2）、H2 样式（左侧竖线或你的分节符号）、引用块用途约定（金句/判断，不用于普通解释）、图注样式（紧贴图、对齐方式）
2. **复制版规则**：公众号编辑器粘贴的要求——图片转 data URI、参考资料区弱化；产出 `*.wechat-article-copy.html` 之类的"可直接复制"版本
3. **验证清单**：渲染后必查项（缺图 / 拉伸 / 图文错位 / 一屏连续灰字）

参考 [wechat-editorial-workflow.md](wechat-editorial-workflow.md) 第 6 节的默认排版与验证项，把它当成起点改成你自己的。

## 注册方式

1. skill 目录放 `skills/<name>/SKILL.md`（frontmatter 含 name / description / argument-hint）
2. 加进 `install.sh` 和 `uninstall.sh` 的 `SUB_SKILLS` 数组（计数注释同步 +1）
3. 跑 `bash tools/verify-package.sh` 确认声明数与目录数一致

## 为什么不提供默认实现

校准循环的其余部分（打分 / 预测 / 复盘 / rubric 进化）是**方法论**，人人通用；配图和排版是**表达层**，通用默认值的结局是所有人的号长一个样。这里留白是刻意的。
