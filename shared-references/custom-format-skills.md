# 配图 / 排版 skill 引导搭建

> **什么时候走这个流程**：用户说"建配图 skill"、"建排版 skill"、"我想要自己的封面风格"之类的话；或 cheat-init Phase 5 之后用户表示想继续。
>
> **核心原则**：配图和排版是表达层——风格即品牌，工具不提供默认实现。这个文件是**引导脚本**，不是说明书：你（agent）按下面的流程问，用户按舒服的方式答。每一步都可以跳过。

## Phase 0：建哪个

问用户：

```
配图和排版这两个 skill 是你的品牌层，我不自带模板——
默认值的结果就是所有人的号长一个样。

想建哪个？
a) 配图 skill（封面 + 插图的风格与规格）
b) 排版 skill（正文的字号、行高、分节样式这些）
c) 两个都建
d) 现在不建（以后随时说"建配图 skill"就能回来）
```

选 d 就停在这里，不要追问。选 a/b/c 进入 Phase 1（c 则两个各走一遍 Phase 1-3）。

## Phase 1：输入方式（每个 skill 各问一次）

```
你想怎么告诉我你的风格？三种都行：

a) 发截图 —— 把你觉得好的公众号博主封面/正文排版、或小红书上喜欢的排版，
   截图直接贴进对话（或给我图片文件路径）。我能看图。
   3-5 张同一个博主的最好，能看出稳定规律；一张也行。
b) 语言描述 —— 说说你想要的样子：什么色系、什么感觉、有没有参考账号。
c) 混合 —— 截图为主，再补几句你想要的调整。
d) 这个先跳过
```

- 截图来源提醒一次即可：公开平台的内容截图直接用；**私聊截图不要发**。
- 用户贴图后**逐张读图**，不要跳过看图直接问问题。

## Phase 2：拆解与确认

你从截图/描述里提炼风格要素，**先给用户看你的拆解结果，确认后再落盘**。

**配图 skill 要拆出**：

1. 封面规格：平台尺寸（公众号 2.35:1 横版 / 小红书 3:4 竖版）、标题字数上限、固定视觉元素（栏目标签 / 色系 / 字体倾向）
2. 插图角色体系：照 [wechat-editorial-workflow.md](wechat-editorial-workflow.md) 第 3 节的六类图角色（锚点 / 冲突 / 数据 / 机制 / 人物场景 / 收束），逐类确认产岀形式——真截图、重绘简化图、还是 AI 生成图
3. 若走 AI 生图：风格约束写死（色调、构图、禁忌元素），别每次生图重新掷骰子
4. contact-sheet 约定：一次出全部图的缩略拼版，方便人眼过质量

**排版 skill 要拆出**：

1. 主题要素：正文边距、行高（公众号建议接近 2）、H2 样式（左竖线 / 你的分节符）、引用块用途、图注样式
2. 复制版规则：公众号编辑器粘贴要求——图片转 data URI、参考资料区弱化
3. 验证清单：渲染后必查项（缺图 / 拉伸 / 图文错位 / 连续灰字）

参考 [wechat-editorial-workflow.md](wechat-editorial-workflow.md) 第 6 节的默认排版项当起点，但**以用户的截图和描述为准**——默认值只是用来填用户没说的空隙。

呈现方式：

```
我从你的截图里看到的是：
- 封面：…
- 正文：…
- 配色：…
有哪里不对/要调的？说"就这样"我就落盘。
```

## Phase 3：生成与注册

用户确认后：

1. 写 `skills/<name>/SKILL.md`（命名建议 `<用户名>-visual` / `<用户名>-layout`），frontmatter 含 name / description / argument-hint；**description 里写清触发词**（"配图"、"封面"、"插图" / "排版"、"格式化"），主路由靠它找到这个 skill
2. 内容多的话拆 `references/` 子文件，SKILL.md 保持精简
3. 把 skill 名加进 `install.sh` 和 `uninstall.sh` 的 `SUB_SKILLS` 数组，计数注释同步 +1
4. 跑 `bash tools/verify-package.sh` 确认声明数与目录数一致

## Phase 4：试跑

```
建好了。找篇旧稿子试一发？说"给 <某篇> 配个封面"或"把 <某篇> 排版一下"。
不满意就说哪里不对，我改 SKILL.md——风格 skill 是改出来的，不是一次写对的。
```

试跑结果不理想 → 改 skill 文件再试，这个循环是正常的，不要当成失败。

---

**给 agent 的提醒**：这个流程的语气和 cheat-init 保持一致——像朋友带着设置，不像审问卷。用户答得简略就用截图补，用户答得详细就少问。跳过永远合法。
